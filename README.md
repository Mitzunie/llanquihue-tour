# Llanquihue Tour

## Descripción
Aplicación Java que lee información de tours desde un archivo
de texto, crea objetos Tour y los almacena en un ArrayList.

## Estructura de carpetas

```
src/
├── model/
├── data/
└── ui/

resources/
└── tours.txt
```

## Instrucciones para ejecutar la clase Main

1. Abrir el proyecto en IntelliJ IDEA.
2. Ejecutar la clase Main.java ubicada en src/ui/Main.java.
3. El sistema cargará los tours desde tours.txt.
4. Mostrará todos los tours y luego filtrará aquellos cuyo
   precio sea superior a $25.000.
